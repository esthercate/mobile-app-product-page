# Bible Study Tracker - Landing Page

A modern, responsive landing page built with Next.js and Tailwind CSS for a Bible Study Mobile Tracker application. The landing page introduces the app, highlights its features, and encourages users to explore or download it.

### Homepage Dark & Light Mode

![Homepage](/public/images/Darkmode.png)

![Homepage](/public/images/Lightmode.png)


## Live Demo

- [Live Link](https://m-pesa-expense-tracker.vercel.app/)


## Features Highlighted on the Landing Page

- Chapter-by-Chapter Tracking

- Automatically track progress within each Bible book

- When all chapters in a book are completed, the book is marked as finished

- Create personalized reading plans based on your interests

- Switch between different Bible versions


## Technologies Used

- **Next.js** – React Framework
- **TypeScript** - Business logic
- **Tailwind CSS** – Styling
- **Vercel** – Deployment
